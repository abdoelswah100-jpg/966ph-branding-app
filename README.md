# 966Ph Branding (تطبيق أندرويد)

تطبيق كميات الدعاية لصيدليات الدواء (966 Motors). نفس تطبيق الـ HTML، ملفوف كتطبيق أندرويد بـ Capacitor.

## إزاي الـ APK بيتبني
- أي تحديث يترفع على فرع `main`، و GitHub Actions بيبني الـ APK لوحده (حوالي 8 دقايق).
- الـ APK بيظهر في **Releases** (باسم الإصدار، مثلًا `v1`) وفي **Actions ← آخر تشغيل ← Artifacts**.
- رقم الإصدار في `package.json`: `appVersion` (الاسم، مثلًا v1.1) و `versionCode` (رقم بيزيد 1 مع كل تحديث). الإصدار الحالي: **v1.2** (versionCode 3).
- بلجن البصمة: `@capgo/capacitor-native-biometric` 6.0.5 (اسمه جوه التطبيق `NativeBiometric`) + صلاحية `USE_BIOMETRIC`.

## الملفات
| الملف | الوظيفة |
|---|---|
| `www/index.html` | التطبيق نفسه (نفس ملف الـ HTML بتاع اللاب توب، ومعاه خط Cairo) |

| `keystore/966ph-release.jks` | **مفتاح التوقيع. ما يتمسحش أبدًا.** أي تحديث لازم يتوقّع بيه علشان يتسطّب فوق القديم من غير ما البيانات تضيع |
| `keystore/password.txt` | باسورد المفتاح (لو اتحط Secret باسم `KS_PASS` في إعدادات المستودع، هو اللي بيستخدم) |
| `.github/workflows/build-apk.yml` | خطوات البناء |

## تثبيت التطبيق على الموبايل (للفريق)
1. افتح ملف `966Ph-Branding-v1.2.apk` (أو أحدث إصدار) اللي وصلك على واتساب.
2. لو ظهر "لأسباب أمنية لا يمكن تثبيت تطبيقات غير معروفة": اضغط **الإعدادات** ← فعّل **السماح من هذا المصدر** (واتساب أو مدير الملفات) ← ارجع واضغط **تثبيت**.
3. لو ظهر تحذير Play Protect: اضغط **تفاصيل إضافية** ← **التثبيت على أي حال**.
4. افتح التطبيق، ومن ☰ ← **الإعدادات العامة** اكتب اسمك كمشرف افتراضي.
5. علشان تاخد بيانات حد تاني: تبويب **النسخ** ← **استعادة كاملة** (لو أول مرة) أو **استيراد ودمج التغييرات** (ملف المزامنة).
